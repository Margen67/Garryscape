# Source recovery

The original untracked converter was lost when its cloud environment was replaced.
This implementation was rebuilt from the user's requirements and the supplied
2009Scape cache, rather than recovered from the old ZIP. The original release
numbers and its NPC, animation, ragdoll, object, and collision implementations
are not part of this rebuilt terrain milestone.

The supplied split cache archive was recovered successfully. Reading its native
JS5 files finds 3,682 map groups; `m50_50` is archive 5/group 382, with a verified
compressed CRC of 2810179905. The cache remains outside the repository.

See [README.md](.github/README.md) for the supported terrain workflow and remaining milestones.
